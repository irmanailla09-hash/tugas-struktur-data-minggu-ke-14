# tugas-struktur-data-minggu-ke-14
Penjelasan Program Note-Taking Sederhana
Program tersebut merupakan aplikasi pencatat sederhana yang dibuat menggunakan bahasa Python. Program ini berfungsi untuk menyimpan catatan, memberikan beberapa tag pada setiap catatan, menampilkan catatan berdasarkan urutan tertentu, serta menyimpan riwayat perubahan terbaru.
Pada program ini terdapat beberapa bagian utama yang saling bekerja sama agar aplikasi dapat berjalan dengan baik.
Bagian pertama adalah pembuatan class Note. Class ini digunakan sebagai template atau bentuk dasar dari sebuah catatan. Setiap note memiliki judul, isi catatan, dan beberapa tag. Tag digunakan untuk memberi kategori pada note agar lebih mudah dicari. Misalnya tag “kuliah”, “tugas”, atau “penting”. Satu note dapat memiliki lebih dari satu tag sehingga pencarian data menjadi lebih mudah dan lebih fleksibel.
Program juga menggunakan list untuk menyimpan semua note yang telah dibuat. Setiap kali pengguna menambahkan catatan baru, data tersebut akan dimasukkan ke dalam list sehingga dapat ditampilkan kembali kapan saja.
Selain itu, program memiliki fitur recent changes atau riwayat perubahan terbaru. Fitur ini digunakan untuk mencatat aktivitas terakhir yang dilakukan pengguna, misalnya saat menambahkan note baru. Penyimpanan recent changes menggunakan circular buffer sehingga jumlah data yang disimpan terbatas. Jika kapasitas sudah penuh, maka data paling lama akan otomatis diganti dengan data baru. Dengan cara ini, program tetap ringan dan tidak menyimpan terlalu banyak riwayat.
Program menyediakan fitur tambah note yang memungkinkan pengguna memasukkan judul, isi catatan, dan jumlah tag yang diinginkan. Setelah data dimasukkan, note akan tersimpan ke dalam sistem dan riwayat perubahan juga akan diperbarui.
Fitur berikutnya adalah chronological view. Fitur ini digunakan untuk menampilkan catatan berdasarkan urutan waktu penambahan. Note yang pertama dibuat akan muncul lebih dahulu, kemudian diikuti note berikutnya sesuai urutan penyimpanan.
Program juga memiliki alphabetical view yang digunakan untuk menampilkan catatan berdasarkan urutan abjad judul note. Dengan fitur ini pengguna dapat mencari note dengan lebih cepat karena data sudah tersusun rapi secara alfabet.
Selain itu terdapat fitur pencarian berdasarkan tag. Pengguna cukup memasukkan nama tag tertentu, lalu program akan menampilkan semua note yang memiliki tag tersebut. Fitur ini sangat membantu jika jumlah catatan sudah banyak.
Pada bagian akhir terdapat menu utama yang digunakan untuk memilih fitur yang ingin dijalankan. Program akan terus berjalan sampai pengguna memilih menu keluar.
Secara keseluruhan, program ini merupakan contoh sederhana penggunaan struktur data dalam aplikasi note-taking. Struktur data yang digunakan meliputi list untuk menyimpan note, multi tag untuk menghubungkan satu note dengan beberapa kategori, sorting untuk pengurutan data, dan circular buffer untuk menyimpan riwayat perubahan terbaru.
